# RSA Crypteur PyQt6

Application Python pour générer, chiffrer et déchiffrer des messages RSA via une interface graphique PyQt6.

## Fonctionnalités
- Génération de clés RSA avec taille configurable.
- Chiffrement et déchiffrement de messages texte.
- Affichage clair des clés publiques et privées.
- Onglet explicatif sur le fonctionnement du RSA.

## Installation
Voir [INSTALL.md](INSTALL.md)

## Usage
1. Lancer `main.py`
2. Dans l'onglet RSA :
   - Générer les clés
   - Chiffrer un message
   - Déchiffrer une liste de nombres
3. Lire l’onglet Explications pour comprendre le RSA.
